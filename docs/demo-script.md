# Demo 录制脚本

目标时长约 2–3 分钟。当前为录制方案，尚无已录制或已上传的视频。录制应使用实际麦克风和普通游戏入口，不以文本注入、合成音频或后期配音替代操作证据。

## 录制准备

- 使用冻结提交启动，记录提交哈希、系统、浏览器、麦克风和识别模式；先完成对应环境实机验收。
- 关闭通知及无关窗口，只录制游戏页和必要的麦克风音轨；检查能同时听到口令和看到棋盘。
- 预先准备模型和浏览器缓存，正式片段不重复展示下载等待。说明模型已预加载，不宣称首次启动无需下载。
- 普通入口不得含 `?debug=1`；页面完整显示棋盘、识别反馈与状态。页面“识别结果到转向”不作为端到端延迟展示。

## 连续演示

| 时间参考 | 操作与口述 | 画面依据 |
| --- | --- | --- |
| 0:00–0:15 | 简述“Voice Snake，以短语音口令操控的网页贪吃蛇”；展示本地中文识别模式 | 项目名称、普通入口和所选模式 |
| 0:15–0:30 | 手动开始、授权，完成倒计时；说明此后局内通过语音操作 | 正在监听、倒计时、蛇开始移动 |
| 0:30–1:05 | 根据当前方向依次说“上、左、下、右”，保持合法转向，择机吃食物 | 连续转向、实际蛇头移动、计分变化；未吃到不宣称成功 |
| 1:05–1:25 | 说“暂停”，等待两秒，再说“继续” | 暂停时棋盘不移动；语音继续后恢复 |
| 1:25–1:45 | 在前方空间充足时说“不要向左”；再用合法方向继续 | 无额外转向；若误触如实记录并修复，不剪接成通过 |
| 1:45–2:05 | 接近边缘时展示一次缓冲内语音转向；再次接近后不发指令，等待超时 | 黄色边界缓冲、转向脱离；另一轮正常碰壁结算 |
| 2:05–2:25 | 说“再来一局”，开局后说“结束游戏” | 分数与长度重置；结束后监听停止 |
| 2:25–2:45 | 简述已测环境和待验证范围 | 不宣称未测的 macOS、真人准确率或灵矽接入已完成 |

时间仅为参考，以实际游戏状态为准；当前方向不允许的口令应调整顺序，不能用剪接掩盖非法转向或误识别。核心操作片段保持连续；故障或重录与最终材料分别保留。

## 输出与核对

文件建议为 `voice-snake-demo-<短提交哈希>.mp4`。本地原始视频放在 `test-results/demo/`，不提交 Git。上传经确认的交付位置后，在交付清单记录 URL、访问权限和对应提交。使用未登录窗口验证观看权限；只在实际验证后将视频标为完成。
