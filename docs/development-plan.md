## 验收标准

测试方案与统计定义统一见[测试报告](validation.md)。以下为项目内部标准，不是比赛官方评分规则：

- Windows/macOS × Chrome/Edge 四个组合分别验收，并记录系统、浏览器、识别方案及版本。
- 每组合 50 条有效口令和 10 条负样本，共 200 条有效口令、40 条负样本；正确执行率目标 ≥95%，负样本预期不触发。
- 每组合连续完成 3 局纯语音游戏，覆盖暂停、继续、结算与重开。
- 指令确认延迟中位数目标 ≤250ms，实际转向延迟中位数目标 ≤500ms；分别报告 P95 和失败数，未达到目标时保留实际结果及限制说明。
- 规则测试覆盖反向、碰撞、食物生成、满盘；交互测试覆盖权限、重复、过期、断连、失焦和异常恢复。
- 干净环境按 README 启动；最终文档、视频和实现版本一致，所有交付链接可访问。
