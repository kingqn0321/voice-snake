# 产品设计

更新日期：2026-10-25。本文定义目标版本，当前实现及验证范围见 [README](../README.md)。

## 作品定位

Voice Snake 是以短口令控制的网页贪吃蛇。玩家在 Windows 或 macOS 电脑上打开网页，手动启动并授权麦克风，其后通过语音完成游戏操作。

作品围绕语音操作调整反馈与容错：屏幕绝对方向减少口令理解成本；识别结果和命令执行状态可见；识别中断时暂停，避免失去控制后仍继续移动。

参赛方向为“灵矽应用：语音类游戏”。“灵矽”仅为名称，不要求额外平台接入。项目以电脑网页展示，使用电脑麦克风采集语音，通过识别适配器驱动游戏。

## 功能与规则

| 项目 | 首版设计 |
| --- | --- |
| 棋盘 | 20×20 网格，无穿墙 |
| 初始蛇 | 长度 3，位于中央，向右移动 |
| 移动 | 巡航 500ms/格；方向指令可提前触发一步，最短步间隔 100ms |
| 食物 | 每次生成一个，位置从空格中选择 |
| 得分 | 每吃一个食物加 10 分，蛇长增加一格 |
| 失败 | 撞墙或撞到移动后仍占用的自身格子 |
| 边缘缓冲 | 下一步将撞墙时额外停留最多 1.2 秒等待语音转向；不自动转弯、无效口令不续期、超时判负；撞自身不缓冲 |
| 通关 | 蛇身填满棋盘，不再生成食物 |
| 控制 | 上下左右、暂停、继续、重开、结束 |
| 结算 | 展示分数及通关/碰撞结果，继续接收重开或结束口令 |

初版不包含账号、联网对战、复杂关卡、自由对话、剧情和排行榜服务。限时挑战、加速和音效增强列为可选扩展。

## 操作流程

1. 玩家点击开始并授权麦克风；识别器就绪且页面处于前台后，显示三秒倒计时。
2. 倒计时完成进入游戏，说“上、下、左、右”按屏幕绝对方向移动。
3. 玩家可随时说“暂停”，暂停后说“继续”恢复。
4. 碰撞或填满棋盘进入结算，说“再来一局”重新开始。
5. 说“结束游戏”结束会话并停止监听；再次进入新会话允许手动启动。

倒计时期间内部状态为 READY，语音状态门控不接受游戏命令。暂停及结算期间保持监听。重开直接建立新一局，不重复麦克风授权。

## 语音口令

| 命令 | 口令 |
| --- | --- |
| UP | 上、向上、往上 |
| DOWN | 下、向下、往下 |
| LEFT | 左、向左、往左 |
| RIGHT | 右、向右、往右 |
| PAUSE | 暂停、停一下 |
| RESUME | 继续、继续游戏 |
| RESTART | 重新开始、再来一局 |
| END | 结束游戏、不玩了 |

仅接受完整口令匹配，允许去除空白及句末标点。“不要向左”“上还是下”不触发命令；首版不处理一句多步转向。方向不能直接反向，每个移动周期最多接收一次合法转向；尚无待执行转向时，同向口令不改变方向，也不占用转向机会。已有待执行转向时，后续方向口令不覆盖它。

## 状态与异常

| 状态 | 接受的语音操作 |
| --- | --- |
| READY | 无，等待授权与倒计时 |
| RUNNING | 方向、暂停、重开、结束 |
| PAUSED | 继续、重开、结束；继续/重开要求识别就绪且页面在前台 |
| GAME_OVER | 重开、结束；重开要求识别就绪且页面在前台 |
| ENDED | 无，监听已关闭 |

识别断开、页面隐藏或失焦时立即暂停，清除待执行转向。恢复连接或焦点后仍保持暂停，玩家说“继续”恢复。浏览器级权限撤销、麦克风不可用等故障通过提示引导手动恢复，并单独记录为异常恢复，不计入无人工干预的纯语音流程。

## 反馈

页面展示分数、游戏状态、识别状态、最近识别文本、命令接收/拒绝结果；方向接受和蛇头实际转向分别反馈。转向采用画面及短音效，不逐次语音播报。文本与符号配合表达状态，暂停和结算不改变棋盘尺寸。

## 性能目标

以下为待验证的优化目标，测试口径见[测试报告](validation.md)：

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 正确执行率 | 正确且仅执行一次的有效口令数 / 有效口令总数 | 每个测试环境 ≥95% |
| 指令确认延迟 | 口令说完至页面显示命令接受结果 | 中位数 ≤250ms |
| 实际转向延迟 | 方向口令说完至蛇头首次沿新方向移动 | 中位数 ≤500ms |
| 尾部延迟 | 上述两类延迟各自的 P95 | 首轮报告实测值，暂不承诺阈值 |

巡航 500ms/格不等于转向响应 500ms：本地完整方向 interim 稳定约 16ms 后提前接收，在线备用约 40ms，final 直接接收；下一帧或最短 100ms 步间隔到期即转向，不再等待完整巡航周期。稳定窗口内修订可取消候选，提前接收后的修订不能撤销动作；暂停、继续、重开和结束仍使用最终结果。默认本地中文流式识别采用小块解码，词表限定为游戏口令并保留拒绝路径；更短窗口的误触及慢速口令断句风险需实测。在线备用仅在启动前显式选择。页面显示电平与模块执行耗时，后者不替代端到端测量。每个系统/浏览器组合测 50 条有效口令，方向子集单独统计转向延迟及误触。

## 隐私

普通入口不持久化原始音频或识别日志。验收入口 `?review=1` 仅在主动点击录制后，在内存中保留棋盘画面、麦克风音轨和事件，用户可手动下载，不自动上传。录制工具不提供游戏控制按钮。浏览器识别服务的数据处理以其服务条件为准。测试报告默认只记录预设口令、环境和测量结果；录像经参与者知情同意后保存，上传前检查不包含私人谈话或凭证。
