# Voice Snake / 语音贪吃蛇

通过“上、下、左、右”操控的网页贪吃蛇游戏，面向 Windows、macOS 电脑。玩家手动启动并授权麦克风后，通过语音完成转向、暂停、继续、重开和结束。

## 作品定位

参赛方向为“灵矽应用：语音类游戏”。网页承担棋盘展示、游戏规则和交互反馈；语音输入通过适配器转为标准命令，控制同一套游戏逻辑。灵矽接入方式及网页模拟的参赛适用范围尚待主办方确认，目前可运行的是浏览器语音验证工具，尚不包含灵矽实际接入。

设计重点是短口令操作、明确的指令反馈和识别异常时的安全暂停。方向判断采用固定口令映射，不依赖大模型决策。

## 本地运行

建议使用 Node.js 18 或更新版本，无需安装第三方依赖。在仓库根目录执行：

```sh
node tools/serve.cjs
```

打开终端打印的地址，默认 `http://localhost:4173`；端口占用时服务自动选择后续端口。点击“启动验证”并授权麦克风，说“上、下、左、右、暂停、继续、重新开始、结束游戏”。

当前页面展示识别文本、命令接收/拒绝及模拟状态，不运行真实蛇游戏。“文本调试”可独立检查指令链路，结果标为文本模拟。

目标浏览器为 Windows、macOS 上的 Chrome 和 Edge，实际兼容性见[测试报告](docs/validation.md)。当前浏览器内置识别是实验方案，尚未完成跨平台语音实测。

## 自动测试

```sh
node tests/commands.test.mjs
```

测试覆盖口令解析、指令门控与识别器生命周期。语音正确率、端到端延迟和完整游戏需要另行实测。

## 隐私与运行条件

浏览器内置识别可能使用厂商在线服务，音频可能由厂商处理；可用性受网络、地区和浏览器策略影响。测试前应确认环境及服务的数据处理条件。网页不持久化音频或识别日志，诊断记录仅保存在页面内存。

本地服务仅绑定回环地址，用于开发验证。外部部署要求 HTTPS；需要服务密钥的识别方案由后端或短期凭证接入，密钥不放入网页。
